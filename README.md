# chihab pdf cnv

موقع بحسابات مستقلة: تحويل الصور إلى PDF، دمج الملفات وتقسيمها، وفحص صورة تذكرة اليانصيب.

عدد المستخدمين في الصفحة الرئيسية هو عدد الصفوف في سجل الحسابات وقت فتح الصفحة.

## التشغيل

```bash
npm install
```

انسخ `.env.example` إلى `.env.local` وضع `AUTH_SECRET` بطول 32 حرفًا على الأقل.

بدون `DATABASE_URL` يعمل السجل في ملف محلي `data/db.json` على جهازك. على Vercel يلزم `DATABASE_URL` لأن نظام الملفات هناك لا يحتفظ بالحسابات.

```bash
npm run dev
```

## أدوات PDF

تُبنى الملفات داخل المتصفح. الخادم يحفظ وصف العملية فقط.
